# Viewer head assets

These two open-source head models were copied unchanged from the local LipScan `v_male` and `v_female` packs at the project owner's direction. According to the owner, they were built from measurements and audit findings from LipScan's reverse-engineering and testing work; they are not CD PROJEKT RED game meshes. The names are legacy identifiers. The viewer applies a plain material at runtime. Only the heads are bundled; other pack files are not included.

The local packs' older `character.json` metadata still describes game-derived exports and was not updated when the owner designated these heads for distribution. The owner supplied the provenance above; the discrepancy has not been independently verified from source geometry or creation records.
